# Signmio downloads

Official Android release downloads for [Signmio](https://signmio.app).

This repository contains release binaries only. Signmio is proprietary software;
its source code is not published in this repository.

## Requirements

Android 15 or later.

## Installation and updates

Download the APK attached to a release and open it on your Android device.
If prompted, allow your browser to install apps, then confirm installation.
For an update, install the newer APK over your existing Signmio installation.
You do not need to uninstall the app.

Each release includes a SHA-256 checksum for the APK.
